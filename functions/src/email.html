Es importante mencionar las siguientes consideraciones para el buen desarrollo de este proyecto:

  • El estudiante seleccionado debe cumplir estrictamente con todos los requisitos establecidos en el apartado “Perfil del estudiante de ayudante de cátedra” del proyecto adjunto.
  • Considerar que las becas se aplican únicamente en períodos académicos que el estudiante genere matrícula y arancel, no aplica para otro tipo de servicio, es decir, el estudiante deberá registrar matrícula en el período académico: {{ period }}.
  • En caso de no cumplir con todos los requisitos establecidos, el estudiante no podrá hacer efectivo el porcentaje de beca para la matrícula del siguiente período académico.
  • Si el estudiante seleccionado desde la titulación no cumple con todos los requisitos establecidos y participa de este proyecto, el Vicerrectorado Académico otorgará únicamente un certificado de participación.
